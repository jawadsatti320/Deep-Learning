# 🧠 Deep Learning Projects — CNN & Keyboard Detection

A collection of deep learning experiments built with Python and TensorFlow/Keras, covering **Convolutional Neural Networks (CNN)** for image classification and a custom **pitch/keyboard detection** model trained from scratch.

---

## 📂 Projects Inside

| Notebook | Description |
|----------|-------------|
| `cnn.ipynb` | CNN architecture built and trained for image classification tasks |
| `train_pitch_keyboard_detection.ipynb` | Custom deep learning model to detect pitch and keyboard input patterns |

---

## 🚀 Key Concepts Covered

- Building CNN layers (Conv2D, MaxPooling, Dropout, Dense)
- Data preprocessing and augmentation
- Model training, validation, and evaluation
- Accuracy/loss visualization with Matplotlib
- Saving and loading trained models

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| Python | Core language |
| TensorFlow / Keras | Model building & training |
| NumPy | Data manipulation |
| Matplotlib | Training visualization |
| Jupyter Notebook | Development environment |
